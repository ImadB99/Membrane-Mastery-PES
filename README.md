## About

**Membrane Mastery** is a 3D virtual learning environment, built in Unity, that teaches dairy membrane filtration — microfiltration, ultrafiltration, (and in the future) nanofiltration and reverse osmosis — through interactive, game‑based learning. The official project name is **Process Engineering Simulator** or **PES**. This project is developed for **Food Process Engineering** under **Patrick Wilms**,**Antoinette Kazbar**,**Guiseppe Olivieri** at the **Social Creative Technologies (SCT) Lab**, **Wageningen University & Research**, supervised by Dr Will Hurst.

## Features

- Explore a 3D membrane filtration plant and interact with real process equipment
- Learn core filtration concepts hands‑on instead of from a textbook
- Guided throughout by Membo, your in‑game AI tutor (FUNCTIONAL, BUT NOT ACTIVE DUE TO LICENSING OF BACKEND SOURCE)
- Short, game‑like challenges that reinforce key concepts
- Built for bioprocess and food engineering students

## Getting Started

**Play the game**

Download the game using the green button and clicking donwload zip-file, unzip in windows explorer, and within the unzipped folder you will find an `.exe` which you can run and play the game — no Unity install needed.
