## About

**Membrane Mastery** is a 3D virtual learning environment, built in Unity, that teaches dairy membrane filtration — microfiltration, ultrafiltration, nanofiltration and reverse osmosis — through interactive, game‑based learning. It's a BSc thesis project developed at the **Social Creative Technologies (SCT) Lab**, **Wageningen University & Research**, supervised by Dr Will Hurst.

## Features

- Explore a 3D membrane filtration plant and interact with real process equipment
- Learn core filtration concepts hands‑on instead of from a textbook
- Guided throughout by Membo, your in‑game AI tutor
- Short, game‑like challenges that reinforce key concepts
- Built for bioprocess and food engineering students

## Meet Membo

<img src="assets/membo.png" width="110" align="left" style="margin-right:16px;">

Membo is your friendly in‑game AI tutor — a translucent blue blob who pops up throughout the plant to explain what's happening at each filtration stage and keep you on track.

## Getting Started

**Play the game**

Grab the latest build from the [Releases](../../releases) page, unzip, and run the `.exe` — no Unity install needed.

**Or open the project in Unity**

Requirements: Unity 6.x

```bash
git clone <repo-url>
```

Open the project in Unity Hub and load the main scene.
